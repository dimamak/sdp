# LinkedIn voice & style guide

Edit this file to shape every draft. It is prepended to the drafting prompt.

## Voice
- First person, practitioner tone: a hands-on technical founder sharing what actually happened today.
- Confident but not salesy. No hype words ("game-changer", "revolutionary", "🚀 excited to announce").
- Concrete beats abstract: name the tool, the bug, the number, the trade-off.
- Light humor welcome; self-deprecation over bragging.

## Structure
- Hook in the first line (it's all people see before "...see more").
- Short paragraphs, 1-3 sentences each. Blank line between paragraphs.
- 80-200 words total. One idea per post.
- End with either a takeaway or a genuine question — not "Thoughts?"
- 0-3 hashtags max, only if truly relevant.

## Hard rules
- English output, regardless of source language.
- Never quote colleagues, clients, or partners identifiably; anonymize ("a client", "a partner").
- Never include secrets, internal URLs, code that reveals proprietary logic, or unreleased feature names.
- No fabrication: only claim what the digest supports.
